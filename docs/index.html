01

Install

Clone the repo, create a virtualenv, and pip install -e .. The careeros command is now on your path. Python 3.11+ required; no other runtime dependencies.

02

Run the onboarding wizard

careeros onboard asks where to create your workspace, then asks for your resume or any text describing your background. It calls Claude Haiku once to extract skills, titles, and goals — then writes the result locally. That's the only network call.

03

Your profile is in profile/profile.json

Skills, job titles, years of experience, preferences, and goals — structured, editable JSON. CareerOS reads it fresh on every command, so you can edit it directly at any time.

04

Export and share

careeros export zips your entire workspace. Hand the zip to another CareerOS install, an AI agent, or any tool that reads the workspace manifest. The zip is self-contained — no CareerOS installation required to read it.

Features

Eight phases, one workspace

From onboarding to applying to researching outreach targets — every command reads and writes the same portable workspace, and every real-world action stops for your approval first.

Onboarding & profile extraction

Interactive wizard extracts a structured profile from your resume via LLM — skills, titles, experience, goals — written once, editable anytime.

careeros onboard

Browser-driven job search

Searches LinkedIn, Indeed, and Wellfound through your own logged-in browser session — no separate account to connect — then scores results against your profile.

careeros browse

Auto-apply with real review

Generates a cover letter with an accept/regenerate/quit loop, then fills the actual application form via a platform-specific filler — nothing submits without approval.

careeros apply

Unattended scheduled runs

Run from cron: discovers jobs and auto-applies to anything above a score threshold you set, capped per run, with a complete activity trail for every decision.

careeros discover-and-apply

Company & people research

Browser-fetched, LLM-extracted research on a job's company and the people there — role-classified as IC, EM, hiring manager, or recruiter.

careeros research company / people

Evidence-backed compensation

Pulls real compensation data from a public salary source with an honest confidence rating — never a plausible-sounding number invented from thin air.

careeros research compensation

Approval-gated outreach

Drafts a role-aware message with the same review loop as applying, then sends it by email only after explicit approval — the one place CareerOS acts irreversibly.

careeros outreach send

Runtime-agnostic approval seam

Every command routes through an AgentRuntime interface instead of prompting directly — a local terminal, an automated policy, or a future agent-embedded runtime resolve approvals differently without any command code changing.

careeros/runtime/

Append-only activity log

Every action — both outcomes of any approval decision, not just the success path — appends a timestamped event. Never edited or deleted: a full audit trail.

activity/

Swappable storage, portable workspace

All I/O goes through StorageProvider. Export a zip, hand it to another install or agent — no CareerOS installation required to read it.

careeros export / careeros import
Quickstart

Up and running in five minutes

Python 3.11+ and an Anthropic API key are the only prerequisites. The API key is used once during onboarding; everything else runs offline.

shell 
# clone and install
git clone https://github.com/init-kaushal/careeros
cd careeros
python -m venv .venv && source .venv/bin/activate
pip install -e .

# set your API key (Anthropic, OpenAI, Groq, Ollama, ...)
export ANTHROPIC_API_KEY=sk-ant-...     # Claude (default)
# export OPENAI_API_KEY=sk-...           # or OpenAI
# export CAREEROS_MODEL=ollama/llama3.2  # or Ollama (free, local)

# run the onboarding wizard
careeros onboard
  Workspace path [~/my-career]: 
  Your name: Jane Smith
  Paste your resume (blank line + enter when done):
  ...
  Extracting profile... done.
  Workspace ready at /Users/jane/my-career

# check what was extracted
careeros workspace status
  Workspace:  /Users/jane/my-career
  Version:    schema v1
  Profile:    Jane Smith · Software Engineer
  Skills:     12 skills

# export a portable workspace zip
careeros export
  Exported to /Users/jane/my-career/exports/careeros-export-2026-01-15.zip

Design principles

How it's built

Four constraints that drive every implementation decision.

Your data stays yours

The framework directory and your workspace are separate. Pull framework updates with git pull — it never touches your workspace.

Agent portability

The workspace manifest is the contract. Any agent that reads it can work with your career data without CareerOS installed.

Swappable storage

All I/O goes through StorageProvider. Local filesystem today, remote or encrypted backends tomorrow — business logic doesn't change.

Your browser session, not a scraping API

Browse, apply, and research commands drive Playwright against your own logged-in Chrome — no separate account to connect, no credentials CareerOS has to store.
